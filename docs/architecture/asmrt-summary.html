PROJECT DESIGN / IMPLEMENTATION PLANNED
asmRT
Durable AI Agent Runtime
Powered by asmDB. Orchestrated in Rust.

A runtime for durable multi-agent coordination — not a store for prompts.
Framework-neutral by design. Explicit adapters come later.

01 / THE LOCAL ARCHITECTURE

Many agents. One writer.

One State Actor owns the MCP session and serializes whole logical operations.

One writer per database. asmDB stays unchanged. No engine fork. No FFI.

IN asmDB

Small records. Durable decisions.

  • Task, run and agent IDs
  • Status, owner and attempts
  • Retry deadlines and lease metadata
  • Compact checkpoint markers
  • Short artifact references

OUTSIDE asmDB

Files or object storage hold the payloads.

  • Prompts and full chat history
  • Documents, source code and patches
  • Full tool outputs, logs and large results
  • Full execution snapshots
  • Embeddings and model weights
Fixed 256-byte records tag: 39 bytes max content: 175 bytes max

Rust runs the work. asmDB remembers the state.

Prove crash recovery locally. Add CDC wake-ups, then real intelligence.
A serialized queue is not a multi-row transaction or an exactly-once guarantee.
